# Nadrkometar

Merač Stefanovog raspoloženja. Otvara se na https://ksd966.github.io/nadrkometar/

Na iPhone-u: otvori link u Safariju → Deli → „Dodaj na početni ekran”.
Na Androidu: Chrome meni (⋮) → „Instaliraj aplikaciju”. Radi i bez interneta.

Podaci se čuvaju samo na telefonu. Za razmenu: Podaci → Izvezi podatke, pošalji fajl, drugi ga uveze (uvoz spaja zapise).

Ovaj repo sadrži samo gotovu aplikaciju; izvor i alati su u privatnom repou.
